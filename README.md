# 全国訪問看護経営研究協会 LP

訪問看護ステーション経営者向けの有料会員サービス入会促進ランディングページ

## 🌐 公開URL

**https://jnhc-mra-lp-2026.vercel.app/**

## 📦 リポジトリ

https://github.com/s2525keita3/-jnhc-mra-lp-2026

## 🚀 ローカル開発

```bash
# 依存関係のインストール
npm install

# 開発サーバー起動
npm run dev

# ビルド
npm run build
```

## 📋 サービス概要

| 項目 | 内容 |
|-----|------|
| 月額料金 | 5,500円（税込） |
| 最低契約期間 | 6ヶ月 |
| サービス内容 | ウェビナー・交流会・メルマガ |
